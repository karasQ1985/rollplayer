# RollPlay 项目概览与进度

> 本地/局域网媒体库随机轮播播放器。最后更新：2026-11-06

## 一、是什么

从本地磁盘或 NAS 共享中扫描音频，**每批 20 首随机不放回**播放，播完自动换批，整池播完为「一轮」，轮完询问是否再来一轮；刷新可断点恢复。

两部分组成，无框架、零第三方依赖：

| 部分 | 职责 |
|---|---|
| `server.mjs` | 零依赖 Node 服务：目录枚举、音频过滤去重、扫描缓存、HTTP Range 流播、封面/歌词/刮削代理、静态页面 |
| `public/` | 纯前端：目录管理、扫描进度、批次调度、播放引擎、频谱可视化、全部交互 |

浏览器直连本地盘/网络位置被沙箱拒绝（File System Access API 明确拒绝网络位置，50GB+ 媒体库也需服务端扫描与 Range 流播），所以必须走本地代理。

## 二、运行

- 双击 `start.bat`：检测 Node → 起服务 → 开浏览器（`node\` 内放 `node.exe` 可绿色免安装）。
- 命令行：`node server.mjs`，默认 `http://127.0.0.1:9898/`；端口占用顺延 9899/9900/9901。
- 环境变量：`MP_NO_OPEN=1` 禁自动开浏览器；`MP_PORT` 自定义端口。
- 重启模板（PowerShell）：查 `Get-NetTCPConnection -LocalPort 9898 -State Listen` 取 `OwiningProcess`（字段拼写如此）→ `Stop-Process -Id <pid> -Force` → 等 2s → `$env:MP_NO_OPEN='1'; Start-Process node -ArgumentList 'server.mjs' -WorkingDirectory '<root>' -WindowStyle Hidden` → 等 3s → `Invoke-WebRequest` 验 200。

## 五、关键常量与数据契约

改这些数值前先确认影响面，它们互相耦合（例如封面加宽 312 必须和 `--cx` 的 310 位移一起改）。

**播放器几何与缩放**
`PLAYER_MIN_W=1160`、`PLAYER_MAX_W=2560`、`COVER_EXTRA=312`、`ZOOM_MIN=0.55`、`ZOOM_MAX=1.6`；等比缩放走 Shift，否则横向拉伸。

**封面展开**
- `.player` 默认 `--cx:340px` / `--cover-x:20px`；`.has-cover` 时 `--cx:650px` / `--cover-x:330px`。
- 两者都注册为 `@property`，与 `width`、`transform` 同曲线同长（1.2s `cubic-bezier(.19,1,.22,1)`）。
- 内容左缘与封面左缘间距全程恒为 **320px**；封面右缘 330 与内容起点 340 之间那 10px 由标注给定。
- 裁剪蒙版：`.cover-reveal{clip-path: inset(0 0 0 calc(330px - var(--cover-x)))}`，不用不透明实色底。
- 点击开合：`COVER_LOCK_MS=1300`、`COVER_BOUNCE_LIMIT=6`；捕获期 pointerdown/up 位移 ≤5px 才算点击。

**切歌收拢**
`switchWithCollapse` 设 `switchSettleUntil = now + 1550`，1500ms 后摘 `.settling`；窗口内点击直接吞；覆盖播放/暂停、键盘 `←/→`、媒体键、列表点击 `jumpTo(i)`。

**抽屉**
`EDGE_DWELL_MS=150`、`SLIDE_MS=800`（+150ms 检测预留 = 950ms 全程）、`HOLD_MS=5000`、`RESUME_AFTER_MS=2000`、`DRAWER_PAD=12`（矩形外扩容差）、巡检 `250ms`、收起延迟 `600ms`（到点再复核几何）；钉住状态不参与自动收。

**音量**
`VOL_WHEEL_STEP=0.05`（5%/格）；rAF 每帧消费一步，队列上限 30；气泡显示 1300ms。

**存储键**
`localStorage`：`mp.playerPos`（`{x,y}`）、`mp.playerWidth`（基础宽度，不含 312）、`mp.playerZoom`、`vizParams`、`mp.scrape`；诊断用 `mp.wheelLog`。
`IndexedDB`：目录列表 / 池清单 / 调度状态，`SESSION_VERSION=1`（带 v0→v1 迁移器）。
封面展开状态**不持久化**。

**接口（server.mjs）**
| 方法 | 路径 | 用途 |
|---|---|---|
| POST | `/api/check` | 校验单个目录存在可读 |
| POST | `/api/check-paths` | 批量校验路径存在性（上限 5000），恢复播放前用 |
| POST | `/api/scan` | 创建后台扫描任务，返回 `requestId` |
| GET | `/api/scan-status` | 轮询扫描进度/结果 |
| GET | `/api/files` | 分批拉取音频清单（去重后） |
| GET | `/api/list` | 目录列表 |
| GET | `/api/cover` | 内嵌封面提取（mp3 APIC / flac PICTURE） |
| GET | `/api/cover-art` | 刮削到的封面转发 |
| GET | `/api/lyrics` | 歌词代理 |
| GET | `/api/scrape` | 在线刮削（lrclib / 网易云） |
| POST | `/api/open-dir` | 在资源管理器中定位音频文件（仅文件） |
| POST | `/api/open-path` | 打开目录或定位文件（目录 `explorer.exe "<dir>"`，文件 `/select,"<file>"`） |
| GET | `/stream?path=` | Range 流式播放 |

**调试钩子**
`window.__errs`（加载/运行错误数组）；`document.body.dataset.wheelLog='1'` 开启滚轮原始事件记录，结果写入隐藏节点 `#wheelLogDump` 的 `textContent`（JSON，最近 200 条）。走 DOM 而不用 window 属性 / localStorage，是因为自动化上下文读不到模块作用域挂在 window 上的属性，也写不了 localStorage。

## 八、后续方向（桌面化，仅结论）

若要脱离浏览器常驻（对标 Wallpaper Engine：壁纸模式 + 系统全局音频捕获 + 托盘），规划结论是 **Tauri v2**：前端资产全复用（WebView2），体积 5–15MB、常驻内存 50–120MB，壁纸注入（Progman/WorkerW）与 WASAPI Loopback 全局捕获下沉 Rust，`server.mjs` 的扫描/流播/封面并入 Rust，`nas-provider.js` 网络层废弃改 IPC。Electron 可作快速验证壳。当前未实施。
